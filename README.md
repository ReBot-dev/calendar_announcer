# calendar-announcer

Googleカレンダーの予定を **2日前** に LINE グループへ流す Google Apps Script（GAS）。
サーバー不要・無料。毎日 20 時台に「2日後に始まる予定」を調べ、あれば送る（なければ何も送らない）。

```
📅 10/25(日) の予定（2日後）

【定例ミーティング】
時間：13:00〜15:00
場所：TIB 2F
・進捗共有
・次回イベントの分担
```

- 雛形は **時間・場所** のあとに予定の「説明」欄をそのまま載せる（見出しなし・空なら省略）。場所が空なら「未定」
- タイトルに **「部会」** を含む予定だけ流す（`Code.gs` 冒頭の `TITLE_KEYWORD` で変更、空文字にすると全部流す）
- **非公開**にした予定は流さない（流したくない予定はカレンダー側で「非公開」にする）
- 日をまたぐ予定は、始まる日の分として 1 回だけ流す

## 1. LINE（Messaging API）

LINE Notify は 2025年3月で終了したため、公式アカウントのボットを使う。

1. LINE公式アカウントを作り（Official Account Manager）、「設定 → Messaging API」で Messaging API を有効にする
2. Official Account Manager の
   - 「アカウント設定」で **グループ・複数人トークへの参加を許可する** を ON
   - 「応答設定」で **応答メッセージ OFF／Webhook ON**
3. LINE Developers コンソールのそのチャネルで **チャネルアクセストークン（長期）** を発行してコピー

> **通数に注意**: グループへの送信は「メンバー数 × 送信回数」で数える（[公式の料金説明](https://developers.line.biz/ja/docs/messaging-api/pricing/)）。
> 無料プランは月 200 通なので、例えば 10 人のグループなら月 20 日分まで。超えるとその月は送信が失敗する（GAS からエラーメールが届く）。

## 2. GAS の準備

1. **アナウンス元のカレンダーのアカウント**で <https://script.google.com> を開き、新しいプロジェクトを作る
2. `Code.gs` の中身を貼り付ける
3. 「プロジェクトの設定」でタイムゾーンを **Asia/Tokyo** にする
4. 同じ画面の「スクリプト プロパティ」に以下を追加

   | プロパティ | 値 |
   |---|---|
   | `LINE_CHANNEL_ACCESS_TOKEN` | 手順 1 のトークン |
   | `CALENDAR_ID` | （省略可）メイン以外のカレンダーを使うとき。カレンダーの設定画面の「カレンダー ID」 |

## 3. LINE グループ ID の取得

1. GAS の「デプロイ → 新しいデプロイ → 種類: ウェブアプリ」、実行ユーザー **自分**、アクセス **全員** でデプロイし、URL をコピー
2. LINE Developers の「Messaging API 設定 → Webhook URL」にその URL を貼り、「Webhook の利用」を ON
   （「検証」ボタンはエラー表示になることがあるが、GAS がリダイレクトで応答するためで、実際のイベントは届く）
3. ボットを対象の LINE グループに招待する → 「このグループに予定を 2 日前にお知らせします📅」と返事が来れば成功
   （スクリプトプロパティに `LINE_GROUP_ID` が入っている）
4. 済んだら、「デプロイを管理」でウェブアプリを**アーカイブ**してよい（以後 Webhook は不要）

## 4. 動作確認と開始

GAS エディタで関数を選んで実行する。

1. `preview` … 送らずに、2 日後の文面をログに出す
2. `testSend` … LINE グループにテスト文を送る
3. `setupTrigger` … 毎日 20 時台の自動実行を登録（何度実行しても 1 個に張り直す）

送信に失敗すると、GAS から実行アカウント宛てにエラーメールが届く。

## 変更したいとき

`Code.gs` 冒頭の定数を変える。

- `DAYS_AHEAD` … 何日前に知らせるか（既定 2）
- `ANNOUNCE_HOUR` … 実行する時台（既定 20）。変えたら `setupTrigger` をもう一度実行
- `TITLE_KEYWORD` … 流す予定のタイトルに含まれる語（既定「部会」）
